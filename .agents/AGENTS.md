# Rules for Antigravity

- **ห้ามแก้ไขโค้ดหรือดำเนินการใด ๆ บนเครื่องผู้ใช้โดยพลการเด็ดขาด (Strictly Ask Before Action)**: 
  ห้ามสร้างไฟล์ ห้ามแก้ไขเนื้อหาไฟล์ ห้ามลบไฟล์ หรือสั่งรันคำสั่งคอมมานด์ใด ๆ ทั้งสิ้นโดยพละการของ AI เอง 
  
- **ต้องรายงานและรอคอยคำอนุมัติพิมพ์ยืนยันในแชทก่อนเสมอ (Wait for Explicit Chat Approval)**: 
  ทุกการดำเนินการที่เกี่ยวข้องกับการเปลี่ยนแปลงระบบ จะต้องอธิบายชี้แจงให้ผู้ใช้ทราบล่วงหน้าผ่านทางช่องแชท และรอคอยจนกว่าผู้ใช้จะพิมพ์ส่งคำอนุมัติหรือยืนยันให้ทำ เช่น "อนุมัติ" หรือ "เริ่มทำได้" เท่านั้น AI จึงจะมีสิทธิ์ใช้เครื่องมือรันคำสั่งได้
